# HTTP Mock

>HTTP mock e um recurso para simular respostas de servicos HTTP sem depender de
uma API real em execucao. Ele serve para testar fluxos da aplicacao, validar
integracoes e reproduzir cenarios previsiveis durante o desenvolvimento.

<b>O desenvolvimento do HTTP mock esta temporariamente parado.</b>

Quando for retomado, revisar o estado atual dos modelos, validacoes,
simulacao e execucao antes de continuar novas alteracoes.
